دفتر کارهای من - نسخه آزمایشی ۰.۱

این نسخه یک وب‌اپ نصب‌شدنی (PWA) است و اطلاعات را در حافظه مرورگر همان گوشی ذخیره می‌کند.

برای نصب روی اندروید:
۱) فایل‌ها را روی یک میزبان HTTPS مانند GitHub Pages منتشر کنید.
۲) لینک را با Chrome گوشی باز کنید.
۳) از منوی Chrome گزینه Install app یا Add to Home screen را بزنید.

برای پیگیری توسط ChatGPT:
از دکمه «ارسال گزارش به دستیار» استفاده کنید و متن گزارش را در همین گفت‌وگو ارسال کنید.

توجه: این نسخه هنوز همگام‌سازی ابری، ورود کاربری یا اتصال خودکار به ChatGPT ندارد.
