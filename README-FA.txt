افزونه ساخت نسخه اندروید دفتر کارهای من

محتویات این بسته را در ریشه مخزن GitHub با فایل‌های فعلی ادغام و بارگذاری کنید.
فایل‌های فعلی وب‌اپ (index.html، app.js، style.css، manifest.webmanifest، sw.js و icon.svg) را حذف نکنید.
پس از بارگذاری، در GitHub به Actions بروید و گردش کار Build Android APK را اجرا کنید.
پس از سبز شدن اجرا، از بخش Summary فایل artifact با نام daftar-karha-apk را دانلود کنید؛ داخل ZIP خروجی، فایل app-debug.apk قرار دارد.
این APK یک پوسته اندرویدی برای نسخه وب منتشرشده در GitHub Pages است و برای نمایش برنامه به اینترنت نیاز دارد. داده‌ها طبق نسخه فعلی وب‌اپ در حافظه محلی همان برنامه ذخیره می‌شوند.
